解析球体与监督样本

train_demo.py 准备样本和配置，train_deep_sdf.py 更新网络。球体内部距离为负，外部为正，表面为零。

class SphereSDF(SDFBase):
    def __init__(self, radius):
        self.radius = radius

    def __call__(self, queries):
        distances = np.linalg.norm(queries, axis=1) - self.radius
        return distances.reshape(-1, 1)

queries 是 N×3 坐标，axis=1 为每个点计算到原点的距离，减半径后返回 N×1 的欧氏 SDF。

脚本固定 NumPy 采样种子为 42，在 [-1,1]³ 给半径 0.4、0.6 的球各均匀采样 20,000 点。按符号保存为 pos、neg 数组，每行是 [x, y, z, sdf]，并检查非空、列数和数值有限性。NumPy 种子控制采样；完整训练还涉及 PyTorch 随机初始化和抽样。

查看 train_demo.py 完整代码 
import json
import os
from pathlib import Path
import numpy as np
from SdfSampler.sdf_sampler import SDFSampler, SDFBase

root = Path(os.environ["NTE_ROOT"])
data = root / "data" / "smoke"
exp = root / "experiments" / "smoke"
exp.mkdir(parents=True, exist_ok=True)

class SphereSDF(SDFBase):
    def __init__(self, radius):
        self.radius = radius
    def __call__(self, queries):
        return (np.linalg.norm(queries, axis=1) - self.radius).reshape(-1, 1)

np.random.seed(42)
sampler = SDFSampler(
    outdir=str(data / "SdfSamples"),
    splitdir=str(exp),
)
info = {"dataset_name": "Smoke", "class_name": "sphere"}
ids = sampler.sample_sdfs(
    [SphereSDF(0.4), SphereSDF(0.6)],
    info, n_samples=20000,
)
sampler.write_json("train.json", info, ids)

for p in data.rglob("*.npz"):
    with np.load(p) as arrays:
        for key in ("pos", "neg"):
            a = arrays[key]
            assert a.ndim == 2 and a.shape[1] == 4
            assert len(a) > 0 and np.isfinite(a).all()

spec = json.loads(
    (root / "DeepSDF/examples/sofas/specs.json").read_text()
)
spec.update({
    "Description": "Installation smoke test on two spheres",
    "DataSource": str(data),
    "TrainSplit": str(exp / "train.json"),
    "CodeLength": 16,
    "NetworkSpecs": {"dims": [64, 64, 64]},
    "NumEpochs": 2,
    "SnapshotFrequency": 1,
    "AdditionalSnapshots": [],
    "LogFrequency": 1,
    "SamplesPerScene": 1024,
    "ScenesPerBatch": 2,
    "DataLoaderThreads": 0,
})
spec.pop("TestSplit", None)
(exp / "specs.json").write_text(json.dumps(spec, indent=2))
print("Smoke experiment:", exp)

配置字段的含义

两个球体的实验设置
字段含义
DataSourcedata/smoke，加载器会拼接 SdfSamples/
TrainSplit训练实例的名称和顺序
NetworkSpecs.dims[64, 64, 64]，三个隐藏层的宽度
CodeLength16，每个球对应一个可训练潜向量
SamplesPerScene1024，每次从一个球的正负样本各抽取 512 点
ScenesPerBatch2，两个球构成一个批次，每轮一次优化器更新
NumEpochs训练结束的总轮数
SnapshotFrequency编号检查点保存间隔
LogFrequencylatest 检查点和日志更新间隔
ClampingDistance0.1，训练时把预测和真值截断到 ±0.1 后计算距离损失

网络同时优化共享解码器和每个球的潜向量。原配置从沙发示例继承学习率计划和正则化，再改用小网络。两轮只有两次优化器更新，适合检查流程，通常不足以拟合清晰球面。

续训到 1000 轮

保持数据、网络结构和实例顺序，修改已有实验的总轮数及保存间隔，再从相应检查点恢复。

python - <<'PY'
import json
import os
from pathlib import Path

path = Path(os.environ["NTE_ROOT"]) / "experiments/smoke/specs.json"
specs = json.loads(path.read_text())
specs.update(NumEpochs=1000, SnapshotFrequency=100, LogFrequency=25)
path.write_text(json.dumps(specs, indent=2) + "\n")
PY

cd "$NTE_ROOT/DeepSDF"
CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=4 \
  python train_deep_sdf.py \
  -e "$NTE_ROOT/experiments/smoke" \
  --continue 2

--continue 2 从第 2 轮结束状态恢复，日志显示 starting from epoch 3。总轮数 1000 表示训练到第 1000 轮。已完成 500 轮时用 --continue 500；中断后用 --continue latest 从最近一次完整保存恢复。

每 100 轮保存编号检查点，每 25 轮更新 latest。已有第 1000 轮检查点时，直接进入三维可视化。修改网络宽度、潜向量维数或实例顺序后，应建立匹配的新实验。

如果希望 train_demo.py 下次直接生成较长训练配置，将其中 NumEpochs 改为 1000、SnapshotFrequency 改为 100、LogFrequency 改为 25。

球体实验的意义与后续对照

解析 SDF 可以直接画球。这个实验验证网络从离散点样本恢复形状的流程。增加训练轮数帮助拟合，增加曲面提取网格的分辨率减小离散采样误差。

后续弯曲棒可以用可靠的解析模型或网格作为参考。训练完成后另生成一批射线，在参考模型和学习模型上分别计算最近交点、进入/离开位置、材料穿越顺序与耗时。例如参考棒内路径长 0.80 mm，学习模型给出 0.73 mm，即使图形接近，路径长度已有差异。这样的几何检查更接近输运程序的使用方式。
