为什么用球体训练

球体解析 SDF 为 d(x, y, z) = sqrt(x² + y² + z²) − r，它能直接用于曲面提取。这里用答案已知的球体，检查采样、训练、检查点保存和曲面重建能否贯通。

SdfSampler 把解析函数变成 [x, y, z, sdf] 监督样本。DeepSDF 用共享解码器 fθ(z, x) 学习形状，每个球各有一个潜向量 z。可视化时在规则网格上查询训练好的网络，再提取零等值面。

解析 SDF → 点样本 → DeepSDF 训练 → 预测距离场 → SDF = 0 球面

两个训练球的半径为 0.4 和 0.6。重建它们可以检查训练拟合效果；对未见形状的恢复能力需要另设测试实例。DeepSDF 使用共享模型表示一类形状，这也是后续变形燃料棒实验可以探索的方向。DeepSDF 论文

部署与实验路线

环境安装

Miniforge、独立环境和缓存，本地 cu124 wheel 安装，以及旧版 DeepSDF 兼容补丁。

球体训练

解释 train_demo.py，完成两轮测试，再从检查点续训到 1000 轮。

三维可视化

导出 PLY，或用 Python 生成自包含 HTML，在浏览器中旋转和缩放球面。
