连接服务器并创建环境

先在本地终端登录，再逐段执行服务器命令。已有环境可直接使用下方激活脚本。每段成功后再继续下一段。

ssh amd128

export HY3D_ROOT=/home/ps/jishaobin/research-field-NTE
cd "$HY3D_ROOT"
source "$HY3D_ROOT/miniforge3/etc/profile.d/conda.sh"
export CONDA_PKGS_DIRS="$HY3D_ROOT/.cache/conda-pkgs"

conda create -y \
  --prefix "$HY3D_ROOT/envs/hunyuan3d2" \
  --override-channels -c conda-forge \
  python=3.10 pip

创建专用激活脚本，集中设置缓存、临时目录和所用 GPU。

cat > "$HY3D_ROOT/activate-hunyuan3d2.sh" <<'BASH'
export HY3D_ROOT=/home/ps/jishaobin/research-field-NTE

export U2NET_HOME="$HY3D_ROOT/.cache/hunyuan3d2/rembg"
export PIP_CACHE_DIR="$HY3D_ROOT/.cache/hunyuan3d2/pip"
export TMPDIR="$HY3D_ROOT/.tmp/hunyuan3d2"

# 物理 GPU 1 在当前进程中对应 cuda:0。
export CUDA_VISIBLE_DEVICES=1

export MAX_JOBS=8

mkdir -p "$HF_HOME" "$TORCH_HOME" "$U2NET_HOME" \
  "$PIP_CACHE_DIR" "$TMPDIR"

if [ -x "$CONDA_PREFIX/bin/nvcc" ]; then
  export CUDA_HOME="$CONDA_PREFIX"
  export PATH="$CUDA_HOME/bin:$PATH"
fi
BASH

source "$HY3D_ROOT/activate-hunyuan3d2.sh"
nvidia-smi

重新 SSH 登录后执行下面一行恢复环境。运行前查看显卡占用，按需调整脚本中的 CUDA_VISIBLE_DEVICES。

获取代码并安装依赖

首次获取项目时执行克隆。已有仓库可直接进入目录。先安装指定的 GPU 版 PyTorch，再用版本约束安装项目依赖。

先生成几何模型

首次调用会下载几何权重，去背景还可能触发额外模型下载。先使用官方示例图片，确认导出成功后再替换自己的图片。

cd "$HY3D_ROOT/Hunyuan3D-2"

cat > infer_shape_local.py <<'PY'
import argparse
from pathlib import Path

import torch
from PIL import Image
from hy3dgen.shapegen import Hunyuan3DDiTFlowMatchingPipeline

parser = argparse.ArgumentParser()
parser.add_argument("--image", default="assets/demo.png")
args = parser.parse_args()

out = Path("outputs")
out.mkdir(exist_ok=True)
image = Image.open(args.image).convert("RGBA")

if image.getchannel("A").getextrema() == (255, 255):
    from hy3dgen.rembg import BackgroundRemover
    image = BackgroundRemover()(image.convert("RGB"))

image.save(out / "input.png")
pipe = Hunyuan3DDiTFlowMatchingPipeline.from_pretrained(
    "tencent/Hunyuan3D-2",
    subfolder="hunyuan3d-dit-v2-0",
    use_safetensors=True,
    variant="fp16",
    device="cuda",
)
mesh = pipe(
    image=image,
    num_inference_steps=30,
    guidance_scale=5.0,
    octree_resolution=256,
    num_chunks=8000,
    generator=torch.Generator(device="cuda").manual_seed(42),
)[0]

assert mesh is not None, "No mesh generated"
assert len(mesh.vertices) > 0 and len(mesh.faces) > 0
mesh.export(out / "shape.glb")
print("Saved:", (out / "shape.glb").resolve())
print("Vertices:", len(mesh.vertices), "Faces:", len(mesh.faces))
PY

set -o pipefail
python -u infer_shape_local.py 2>&1 | tee logs/shape.log

检查 outputs/shape.glb 是否生成，日志中应打印非零顶点数和面数。自己的图片尽量主体完整、背景简单。把下方路径替换为服务器上的实际图片，每次运行会覆盖同名输出。

python -u infer_shape_local.py \
  --image /你的图片绝对路径/input.png \
  2>&1 | tee logs/shape.log

编译纹理模块

纹理阶段需要 CUDA 光栅化扩展和 C++ 网格处理扩展。给独立环境安装 CUDA Toolkit 12.4.1，使编译工具与 PyTorch cu124 对齐。

nvidia-smi 中的 CUDA 版本表示驱动支持能力，编译器版本用 nvcc --version 查看。

conda install -y \
  --prefix "$HY3D_ROOT/envs/hunyuan3d2" \
  --override-channels \
  -c nvidia/label/cuda-12.4.1 \
  -c conda-forge \
  cuda-toolkit=12.4.1

source "$HY3D_ROOT/activate-hunyuan3d2.sh"

生成带纹理的模型

单独启动纹理推理进程，读取上一阶段的网格和去背景图片。先清理网格并减面，再加载 Paint Turbo、开启 CPU offload。首次运行会下载纹理与去光照权重。

cd "$HY3D_ROOT/Hunyuan3D-2"

cat > infer_texture_local.py <<'PY'
from pathlib import Path

import trimesh
from PIL import Image
from hy3dgen.shapegen import (
    FloaterRemover,
    DegenerateFaceRemover,
    FaceReducer,
)
from hy3dgen.texgen import Hunyuan3DPaintPipeline

out = Path("outputs")
image = Image.open(out / "input.png").convert("RGBA")
mesh = trimesh.load(out / "shape.glb", force="mesh")
mesh = FloaterRemover()(mesh)
mesh = DegenerateFaceRemover()(mesh)
mesh = FaceReducer()(mesh, max_facenum=40000)

pipe = Hunyuan3DPaintPipeline.from_pretrained(
    "tencent/Hunyuan3D-2",
    subfolder="hunyuan3d-paint-v2-0-turbo",
)
pipe.enable_model_cpu_offload()
mesh = pipe(mesh, image=image)
mesh.export(out / "textured.glb")
print("Saved:", (out / "textured.glb").resolve())
PY

set -o pipefail
python -u infer_texture_local.py 2>&1 | tee logs/texture.log

完成后应生成 outputs/textured.glb。两个阶段的日志分别保存在 logs/shape.log 和 logs/texture.log。

常见问题

从发生错误的步骤和对应日志开始定位。

现象检查与处理
torch.cuda.is_available() 为 False确认已激活 envs/hunyuan3d2，PyTorch 为 cu124 版本，且 nvidia-smi 能看到 GPU。
CUDA 编译版本不匹配检查 which nvcc、nvcc --version 和 CUDA_HOME，应指向独立环境内的 12.4。
缺少光栅化或网格扩展检查两个扩展的安装日志，再运行扩展导入检查。
CUDA out of memory检查其他 GPU 任务。几何阶段可将 octree_resolution 降到 192、num_chunks 降到 4000；纹理阶段确认启用 CPU offload。
Hugging Face 下载超时检查模型下载网络，再重试对应推理命令。项目页面可访问后，仍需确认权重下载成功。
依赖安装或导入冲突执行 python -m pip check，核对约束文件与当前安装版本。
网页缺少纹理功能查看 logs/gradio.log 中的加载错误，先验证扩展导入和纹理权重。
