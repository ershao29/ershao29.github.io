English reading summary of Charles Dapogny and Pascal Frey, Computation of the Signed Distance Function to a Discrete Contour on Adapted Triangulation. Paper source, 25 PDF pages: body pp. 1–23, references pp. 24–25. The original notes were prepared November 9, 2026; no publication year is inferred from PDF creation metadata.

This summary retains the method, implementation requirements, and limitations from the original Chinese chapter notes. The paper computes a numerical SDF on a non-fitted simplex background mesh, combining geometric initialization, characteristic-based propagation, and Hessian-driven anisotropic adaptation.

1. Input, output, and assumptions

Input is a segment contour in 2D or triangle boundary in 3D, plus a background triangulation/tetrahedralization. Output is a continuous piecewise-linear nodal field. The boundary and volume meshes serve different purposes.

Use negative inside, positive outside:

uΩ(x)=s(x)d(x,∂Ω),s∈{−1,+1}.u_\Omega(x)=s(x)\,d(x,\partial\Omega),\qquad s\in\{-1,+1\}.

The method avoids requiring a fitted background mesh or preassigned outward normals, but still assumes a meaningful bounded region. Orientability alone does not repair arbitrary open, self-intersecting, or nonmanifold triangle soups. Nested boundaries require explicit region semantics.

Exact continuous SDFs, exact nodal samples, and numerically propagated nodal values are three distinct objects. Even exact nodal values can lose a small enclosed feature when every vertex of its containing simplex lies outside.

2. Continuous propagation and characteristic update

The reinitialization equation is

ut+s(x)(∥∇u∥−1)=0,u|∂Ω=0.u_t+s(x)(\|\nabla u\|-1)=0,\qquad u|_{\partial\Omega}=0.

The continuous solution framework motivates arrival of correct boundary distance after sufficient pseudotime. This does not prove exactness of discrete values after the same time.

On smooth nonzero-gradient branches, the characteristic velocity is s∇u/∥∇u∥s\nabla u/\|\nabla u\|, and the value changes at rate ss. Backtracking gives the first-order update

un+1(x)≈un(x−sΔt∇un(x)∥∇un(x)∥)+sΔt.u^{n+1}(x)\approx u^n\!\left(x-s\Delta t\frac{\nabla u^n(x)}{\|\nabla u^n(x)\|}\right)+s\Delta t.

At a skeleton, averaging opposing gradients can cancel or invent a spurious direction. The algorithm therefore retains gradients from individual incident elements.

A signed-distance Eikonal statement needs the correct Hamiltonian sign inside: ∥p∥−1\|p\|-1 outside and 1−∥p∥1-\|p\| inside. The original notes show that treating |x|−1|x|-1 inside (−1,1)(-1,1) as a global viscosity solution of the same unsigned Hamiltonian fails at its minimum.

3. Geometric initialization

  1. Detect background elements cut by the input boundary, using adjacency traversal and robust intersection predicates.
  2. Mark all vertices of those elements as fixed seed nodes.
  3. Compute each seed's true minimum distance to the complete discrete boundary using point-segment/point-triangle queries.
  4. Classify node signs. Initialize nonseed values to s(x)Umaxs(x)U_{max}.

Seed distance requires the nearest boundary primitive globally. Restricting the search to primitives intersecting the current background element needs an additional completeness argument. A BVH is a reasonable implementation choice, not a mandated data structure in the paper.

The layered sign-assignment algorithm starts outside the bounding box and alternates signs across boundary bands. Its printed pseudocode contains undefined Stratum and inconsistent Sign/Sgn, and leaves cut-band vertex classification incomplete. Nearby merged bands, multiple crossings in one cell, and tiny enclosed objects need robust classification or refinement. A whole cut cell cannot simply be assigned one sign.

4. Discrete propagation

For each incident simplex TT, compute the old-field constant gradient gTg_T. For a nonseed vertex xx, form

yT=x−s(x)ΔtgT∥gT∥,qT=un−1(yT)+s(x)Δt.y_T=x-s(x)\Delta t\frac{g_T}{\|g_T\|},\qquad q_T=u^{n-1}(y_T)+s(x)\Delta t.

Reduce candidates and the old value using minimum outside and maximum inside. An interior value of −0.2-0.2 represents a nearer boundary than −0.3-0.3. Interior initialization must therefore be a large negative value.

initialize exact signed seeds and signed large nonseed values
repeat:
    new = old
    for each element:
        obtain its old-field gradient
        skip or explicitly handle a near-zero gradient
        for each nonseed vertex:
            backtrack using that element's normalized gradient
            locate the backtracked point in the background mesh
            interpolate the old field in the containing element
            reduce the candidate by outside-min or inside-max
    compute residual and swap buffers

Backtracked points can leave the incident element. Locate their actual containing element and interpolate there; unlimited extrapolation of the original element changes the algorithm. The printed scheme reads old values and gradients throughout an iteration, supporting a Jacobi-style double buffer. In-place updates alter propagation order.

Element-parallel candidate generation still needs safe shared-node reductions. Increasing timesteps after initial propagation and freezing reached nodes are acceleration ideas, not unconditional stability or discrete-error certificates. A proposed freezing check uses absolute distance and cumulative pseudotime, not negative interior values compared directly with positive time.

The experimental residual ∑i|uin−uin−1|\sum_i|u_i^n-u_i^{n-1}| measures iteration change, not error to the exact SDF. Total costs include initialization, point location, iteration count, and remeshing.

5. Hessian adaptation and geometry errors

Separate representation and propagation error:

∥uΩ−uh∥≤∥uΩ−π𝒯uΩ∥+∥π𝒯uΩ−uh∥.\|u_\Omega-u_h\|\le \|u_\Omega-\pi_\mathcal T u_\Omega\| +\|\pi_\mathcal T u_\Omega-u_h\|.

The adaptation analysis primarily controls the first term. Linear interpolation reproduces affine functions exactly, so second derivatives, rather than gradient magnitude alone, drive the metric.

For recovered Hessian H=Pdiag(λi)PTH=P\operatorname{diag}(\lambda_i)P^T, the metric is

M=Pdiag(λ̃i)PT,λ̃i=min[max(c|λi|ε,hmax−2),hmin−2].M=P\operatorname{diag}(\widetilde\lambda_i)P^T,\qquad \widetilde\lambda_i= \min\!\left[\max\!\left(\frac{c|\lambda_i|}{\varepsilon},h_{max}^{-2}\right),h_{min}^{-2}\right].

The directional size behaves like ε/(c|λi|)\sqrt{\varepsilon/(c|\lambda_i|)}, clipped to the allowed size range. Absolute Hessian means absolute eigenvalues, not elementwise matrix absolute values. If accuracy requires sizes below hminh_{min}, clipping prevents the nominal target from being guaranteed.

A piecewise-linear element's classical interior Hessian is zero; use recovered neighborhood derivatives or quadratic fits. Recovery, smoothing, symmetrization, and metric gradation are engineering modules requiring validation, not fully specified implementations in the paper.

Under regular-band conditions with 0<m≤∥∇u∥≤L0<m\le\|\nabla u\|\le L, the paper derives

d(x,{u=0})≤Lm2|u(x)|.d(x,\{u=0\})\le \frac{L}{m^2}|u(x)|.

Applying this to the interpolated zero surface relates interpolation error to one-way geometry error. Reverse/Hausdorff control additionally needs suitable discrete gradients and local zero crossings; the paper's combined estimate neglects certain gradient differences. Global smoothness assumptions fail at skeletons and sharp features.

A simpler exact-SDF observation is

∥uh−uΩ∥∞≤δ⇒supuh(x)=0d(x,∂Ω)≤δ.\|u_h-u_\Omega\|_\infty\le\delta \Longrightarrow \sup_{u_h(x)=0}d(x,\partial\Omega)\le\delta.

This direction alone does not prove that every true boundary component has a reconstructed counterpart. Track both directions of Hausdorff distance, topology, thin-feature retention, and volume.

The tangential Hessian eigenvalues relate to principal curvatures; the normal eigenvalue is zero in a smooth SDF neighborhood. Not every ambient Hessian eigenvalue is a surface principal curvature. Narrow-band adaptation can save work, but compare it fairly with methods solving the full domain.

6. Reinitialization and Riemannian extension

Reinitialization adapts near the current zero surface, rebuilds distances, and targets bounded geometric drift. The short discussion does not prove exact volume conservation, invariant topology, retained corners, or bounded cumulative drift over arbitrary repeated cycles.

Distinguish the mesh-design metric, which improves approximation of Euclidean distance, from the distance-defining metric, which changes the target geometry. With a symmetric positive-definite distance metric M(x)M(x),

∇uTM−1∇u=1,aM=M−1∇u∇uTM−1∇u.\sqrt{\nabla u^TM^{-1}\nabla u}=1,\qquad a_M=\frac{M^{-1}\nabla u}{\sqrt{\nabla u^TM^{-1}\nabla u}}.

Replace the Euclidean direction by aMa_M in backtracking; it has unit metric speed, not generally unit Euclidean speed. Spatially varying metrics yield curved geodesics, so one straight backtrack is a local approximation. Seed distances must also use the target metric. General high-accuracy Riemannian seed initialization is not fully supplied. The Poincare half-plane uses M=y−2IM=y^{-2}I.

7. Experiments, implementation route, and proposal value

The original examples illustrate anisotropic savings and geometric reconstruction; they do not establish universal superiority over every SDF method or modern GPU implementations. Extracted surface-mesh quality remains a separate task from adapting the volume mesh, as the Wheel example demonstrates.

A practical implementation order is robust boundary predicates and nearest queries → sign/seed validation → double-buffer propagation and point location → residual and independent error checks → Hessian recovery/metric generation → remeshing and reinitialization against the original boundary. Merely interpolating the old field onto a new mesh can preserve already-lost features.

For the thesis, this paper supports sampled-field construction and geometry-aware adaptation. It does not by itself supply transport-safe field certificates, material/FSR semantics, complete intersections, strict conservation, or a production implementation. Nodewise monotone iteration also does not establish the full operator monotonicity and viscosity-convergence conditions of Hamilton–Jacobi theory.
