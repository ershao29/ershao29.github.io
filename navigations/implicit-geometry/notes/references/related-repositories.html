Related Software Repositories

SDF and Implicit Modeling Repositories

  • Repository: deadsy/sdfx Function: A simple CAD package written in Go for modeling based on signed distance functions. Link: https://github.com/deadsy/sdfx

  • Repository: rohan-sawhney/fcpw Function: An acceleration library for fast geometric queries, supporting closest-point and ray-intersection queries on 3D triangle meshes and 2D segment meshes, with C++ and Python interfaces and GPU acceleration. Link: https://github.com/rohan-sawhney/fcpw

  • Repository: mkeeter/fidget Function: Experimental infrastructure for evaluating complex closed-form implicit surfaces, including a fast JIT compiler and support for expression manipulation, interval evaluation, gradient computation, 2D/3D rendering, and mesh generation. Link: https://github.com/mkeeter/fidget

  • Repository: mitsuba-renderer/drjit Function: A just-in-time compiler for ordinary and differentiable computation, originally created as the numerical foundation of the differentiable renderer Mitsuba 3, supporting automatic differentiation, vectorization, and combined Python/C++ tracing. Link: https://github.com/mitsuba-renderer/drjit

  • Repository: soypat/gsdf Function: A GPU-accelerated 3D/2D CAD design package written in Go. Link: https://github.com/soypat/gsdf

  • Repository: fogleman/tracer Function: A global illumination path tracer written in C++. Link: https://github.com/fogleman/tracer

  • Repository: fogleman/sdfplus Function: A C++ tool that converts SDFs to STL. Link: https://github.com/fogleman/sdfplus

  • Repository: BrunoLevy/geogram Function: A programming library with a rich set of geometry algorithms, providing surface reconstruction, remeshing, parameterization, Boolean operations, CSG, Delaunay triangulation, and other geometry processing functions. Link: https://github.com/BrunoLevy/geogram

  • Repository: BrunoLevy/CSGplusplus Function: An OpenSCAD-compatible wrapper for testing mesh intersection algorithms, including a 2D CSG engine and an OpenSCAD parser. Link: https://github.com/BrunoLevy/CSGplusplus

  • Repository: mmacklin/tinsel Function: A lightweight CPU/GPU path tracer focused on speed and simplicity, supporting Disney BRDF-based BSDFs, HDR environment lighting, motion blur, and other features. Link: https://github.com/mmacklin/tinsel

  • Repository: libfive/libfive Function: An infrastructure framework for solid modeling based on function representation, including a core library, a standard library, and the Studio GUI application, with support for watertight, manifold, feature-preserving mesh generation. Link: https://github.com/libfive/libfive

  • Repository: tunabrain/sparse-voxel-octrees Function: A multithreaded CPU sparse voxel octree implementation in C++ that enables real-time ray tracing of large datasets and supports conversion from raw voxel files or PLY mesh files to octrees. Link: https://github.com/tunabrain/sparse-voxel-octrees

  • Repository: Lixiyao-meow/DeepSDF Function: An implementation of DeepSDF based on the 2019 paper by Park et al., using an auto-decoder to learn and reconstruct signed distance function representations of shapes on the ShapeNet dataset. Link: https://github.com/Lixiyao-meow/DeepSDF

  • Repository: kkmaute/moris Function: Multiphysics Optimization Research and Innovation System, a research platform for PDE-constrained optimization, focusing on shape and topology optimization using isogeometric extended finite element methods. Link: https://github.com/kkmaute/moris

  • Repository: isosuite/gustaf Function: A Python library for processing and visualizing geometries used in numerical analysis. Link: https://github.com/isosuite/gustaf

  • Repository: isosuite/splinepy Function: A Python library for prototyping spline geometries of arbitrary dimension and degree, as well as isogeometric analysis. Link: https://github.com/isosuite/splinepy

  • Repository: marian42/mesh_to_sdf Function: A Python library for computing approximate signed distance fields from arbitrary triangle meshes, including non-watertight, self-intersecting, and non-manifold meshes, with support for voxelization and non-uniform point sampling near surfaces. Link: https://github.com/marian42/mesh_to_sdf

  • Repository: maurock/DeepSDF Function: A simple and intuitive implementation of DeepSDF that can be installed with one line of code. Link: https://github.com/maurock/DeepSDF

  • Repository: christopherbatty/SDFGen Function: A simple command-line tool for generating grid-based signed distance fields from triangle meshes, with code originating from Robert Bridson's website. Link: https://github.com/christopherbatty/SDFGen

  • Repository: sohale/implisolid Function: An open-source geometry engine focused on implicit surface modeling, featuring support for sharp edges and integrating geometry/solid modeling, mesh generation, and slicing. Link: https://github.com/sohale/implisolid

  • Repository: sclaus2/CutCells Function: A library for computing intersections between mesh cells and implicit functions. Link: https://github.com/sclaus2/CutCells
