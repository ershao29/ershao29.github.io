Use the explicit 3D segmentation path as the first investigation target for continuously deformed geometry. Keep material regions, FSR IDs, volumes, and boundary connections consistent before changing sweeps or enabling acceleration.

Shared implementation questions

  • Which layer owns material/instance labels and shared-interface identity?
  • How are origin-on-boundary, tangent, coplanar, and unresolved events represented?
  • Which coordinate transformations preserve distance and ray parameters?
  • Which OTF assumptions rely on axial extrusion?
  • What independent reference checks complete material/FSR sequences and volumes?

The technical roadmap specifies proposed experiments. Existing teaching demos are independent of these solver snapshots.
