1. Hypothesis and scope

Hypothesis: in cores combining complex deformation, thin material layers, and repeated instances, local implicit programs preserving material semantics and bounded interface queries may be cheaper than fine axial slicing or dense surface meshes at equal transport accuracy. This hypothesis does not promise acceleration in every scenario. Analytic CSG may remain fastest for regular planes/cylinders.

Initial restrictions:

  • Finite domain, finite material set, enumerable solid instances, negative-inside/positive-outside convention, and consistent length units.
  • Continuous, piecewise-smooth fields with explicit semantics for periodic seams, nonsmooth Booleans, and contacts.
  • Verifiable parameter ranges; reject undeclared overlaps and negative thicknesses.
  • Initially static geometry, regionwise constant cross sections, and planar outer boundaries; postpone continuous density, curved reflection, and time-dependent geometry.
  • No completeness guarantee for arbitrary black-box functions in finite time. Declare supported function families, degeneracies, and unresolved policies.

2.2 Prototype interfaces

The following is an unimplemented design sketch:

GeometryProgram
  classify(point, direction, previous_event) -> RegionState | Ambiguous
  enclosure(spatial_domain, parameter_domain) -> FieldEnclosure
  boundary_lower_bound(point, state, valid_domain) -> CertifiedBound
  next_event(ray, state, t_limit) -> Hit | NoHit | Unresolved
  segmentize(ray, source_partition) -> OrderedSegments | Unresolved

Hit
  t_interval, representative_t
  interface_ids, region_before, region_after
  event_kind: crossing | tangent | coincident | lattice | external
  normal_or_branch_info, numerical_status

OrderedSegments
  [(t_begin, t_end, material_id, source_region_id, instance_id)]
  endpoint_events, unresolved_intervals, provenance

CertifiedBound means enclosure conditions have been checked; uncertified distance estimates use Estimate. NoHit means valid events were excluded throughout the interval, not that an iteration limit was reached. Unresolved triggers precision escalation or backend fallback and must not be silently discarded in production.

3. OpenMC implementation routes

3.1 Route A: geometry prefiltering as the first feasibility target

DAGMC-SDF established distance-field prefiltering with fallback to original geometry queries. New work should target tighter bounds, deformation updates, instance caches, and error budgets. S24

  1. Provide conservative distances to all currently relevant region boundaries on reference geometry.
  2. At a particle-advancement point where the next candidate physical-event distance is known, determine whether exact boundary queries can be skipped.
  3. Include parent clipping, lattices, and other relevant boundaries; preserve independent tally-mesh track binning.
  4. Use the original exact path when bounds are insufficient; record acceptance, errors, fallback, and extra-query costs.
  5. Compare performance at fixed physics, seeds, and tallies; check physical statistics.

Returning a safe short step from Surface::distance() as a boundary distance injects nonexistent boundaries into event selection. Integrate prefiltering where event semantics are explicit.

For homogeneous macroscopic total cross section Σt\Sigma_t, sc=−lnξ/Σts_c=-\ln\xi/\Sigma_t. With fixed geometry bound bb and event conditions:

P(sc<b)=1−e−Σtb.P(s_c<b)=1-e^{-\Sigma_t b}.

Interpretation of this derivation: prefiltering benefits may grow with Σtb\Sigma_t b, but depend on spatial/energy distributions, bound costs, and hierarchical boundaries. This local probability is not a global speedup.

3.2 Route B: native implicit surface/region extension

OpenMC exposes evaluate, directional distance, and normal, with multilevel coordinates and lattice tracking. S26S27 Candidate work packages:

  • Add bounded complex-surface types and expression serialization; avoid Python callbacks in particle hot loops.
  • Separate compound-solid and individual-surface responsibilities; check that compound zero-surface events are valid in the current cell.
  • Return the nearest valid forward hit from distance, using coincident-surface hints to avoid re-hitting the origin.
  • Preserve stable surface/cell/instance IDs for crossing, tallies, distributed materials, and diagnostics.
  • Validate translations/rotations, parent clipping, lattice exits, vacuum/transmission, then reflection/periodicity.
  • Check compatibility with input, restart, geometry visualization, and stochastic volume calculations.

Initially leave collision kernels and nuclear-data processing unchanged. If geometry is unchanged and only queries differ, test for statistically resolvable response bias under the same statistical design.

4. OpenMOC implementation route

Official documentation includes 3D tracks. Geometry::segmentize3D is a candidate direct-segmentation entry, whereas segmentizeExtruded and related paths assume extrusion. S30S31S32

4.1 Replace geometry segmentation before transport sweeps

  1. Fix existing track origins, directions, weights, and external boundary connections.
  2. Generate all material/FSR segments on the same tracks and convert to solver structures.
  3. Establish sequences and sweep results using explicit storage before on-demand generation/caching.
  4. Compare independent geometric FSR volumes with track integration; detect undersampled tiny regions.
  5. Enable CMFD and other acceleration only after volumes, FSR IDs, and connections agree, isolating geometry from coupling errors.
  6. Validate 3D twisting/bending with fixed planar boundaries before complex reflection.

Source-region boundaries define integration discretization and cannot be merged merely because materials match. Merge adjacent segments only when material, source region, tally, and acceleration-equation states all agree.

4.2 Batching and on-demand segmentation

Compare explicit one-time storage, rebuilding every sweep, and mixed segment/program caches keyed by local geometry version. Write total cost as

T=Tbuild+Tcompile+Ttrack+NsweepTsweep+NupdateTupdate.T=T_{build}+T_{compile}+T_{track} +N_{sweep}T_{sweep}+N_{update}T_{update}.

For static geometry and many sweeps, expensive initial segmentation can amortize; shape updates every iteration change this balance. Track-generation speedup and whole-solver speedup are different metrics.

5. Validation ladder and cases

5.1 Level 0: mathematical and query contracts

ID Case Failure targeted Reference
G0 Planes, spheres, coaxial cylinders/shells Nearest roots, entry/exit, unit scaling Analytic solutions
G1 Gradient-normalized f=x2−1f=x^2-1 Mistaking approximate distance for a safe step Hand calculation
G2 Multi-material thin slabs/shells Two crossings between same-sign endpoints Analytic roots/material sequences
G3 Sphere tangents and nearby rays Multiple roots, tiny chords, root merging Analytic/high-precision results
G4 Coplanar neighbors, touching solids, triple junctions Zero ownership, seams, inconsistent complements Shared interfaces/directional classification
G5 Finite periodic arrays and modulo fields Seam jumps and finite boundaries Explicit instance enumeration
G6 C/S bending and twisted noncircular sections Distance distortion and curved inverse rays High-precision intervals/converged models
G7 Nonuniform scaling and deep transformations Incorrect Lipschitz bounds, interval inflation Computable transformation bounds
G8 Nested universe/lattice clipping Ignored parent/lattice boundaries Reference hierarchical tracking
G9 Parameter perturbations across contact Stale caches and topology changes Complete rebuild

Use random and structured adversarial rays in every class. Deliberately sample near-boundary origins, parallel/grazing directions, ultrathin layers, and multiscale coordinates.

Normalize total geometry scale to 1 and test layer ratios such as 10−2,10−4,10−610^{-2},10^{-4},10^{-6}. These are numerical stress tests, not reactor dimensions. Then verify tolerance scaling in physical units.

5.2 Level 1: fixed source with identical physics

Use nonfission or fixed-fission-source monoenergetic/few-group cases; check leakage, absorption, and regional rates with identical materials, cross sections, and boundaries. This avoids confounding source iteration and continuous-energy/multigroup collapse.

An analytic pure-absorber slab tests e−Σtℓe^{-\Sigma_t\ell} and interface-shift optical-thickness errors. Add scattering to test iterative amplification.

5.3 Level 2: regular-geometry regression

Select public pin/assembly benchmarks such as C5G7 after verifying versions and inputs. First converge implicit and analytic backends under identical discretization, then add bending/twisting.

Caution: deformed public benchmarks become custom derived problems; original reference values no longer apply. Archive original inputs, deformation rules, and new reference-solution procedures together.

5.4 Level 3: continuous deformation and multi-material structures

Geometry family Reference comparisons Main responses
Continuously twisted noncircular fuel Axial-slicing and independent CAD/mesh sequences Axial/radial power, local rates, cost
C/S-bent rods/assemblies Analytic special cases, rotated segments, stacked models Gap flux, power tilt, leakage
Eccentric thin cladding/narrow water gaps Exact-thickness models and mesh convergence Cladding absorption and material chord distributions
Repeated assemblies/simplified core Undeformed regular limit Hierarchical caches, scaling, total time

Agreement between OpenMC and OpenMOC is insufficient if they share the same incorrect kernel. Keep an independent geometry path; validate mesh watertightness, volume, shared faces, and thin-layer convergence. S18S19

5.5 Level 4: multiphysics and derivatives

First fix temperature/density to isolate geometry, then introduce density, temperature, and material mapping under explicit conservation assumptions. Validate simple derivatives before nonsmooth contact transitions. These extensions should not gate the forward-geometry paper.

6. Required metrics

6.1 Geometry correctness

  • Nearest-valid-event error, material-sequence agreement, missed/duplicate interfaces.
  • Maximum segment-length error, material-integrated path error, total-track closure error.
  • Tangency classification, unresolved fractions at coplanar/multiple roots, and fallback outcomes.
  • Consistency across backends, thread counts, coordinate scales, and expression reorderings.
  • Independent FSR volume errors, missed regions, reconstructed volume, and coverage distributions.

For target segment length LL, record

eclose=|∑jℓj−L|max(L,Lscale),e_{close}=\frac{|\sum_j\ell_j-L|}{\max(L,L_{scale})},

where Lscale>0L_{scale}>0 is a predefined small-length scale. Also report absolute errors so normalization does not hide small-scale failures.

6.2 Transport correctness

Record keffk_{eff}, regional flux, normalized power RMS/maximum deviations, absorption/fission rates, leakage, and discrete-balance residuals. Include absolute or volume-weighted errors where low responses distort relative errors.

Use an explicit eigenvalue-difference definition:

Δk[pcm]=105(ktest−kref),\Delta k\,[\mathrm{pcm}]=10^5(k_{test}-k_{ref}),

Distinguish this from reactivity difference 105(1/kref−1/ktest)10^5(1/k_{ref}-1/k_{test}), despite their shared units.

For independent MC estimates, the difference standard deviation is σ12+σ22\sqrt{\sigma_1^2+\sigma_2^2}; correlated sampling requires covariance. Agreement within a broad confidence interval alone does not establish an engineering error target.

6.3 Performance and scaling

Separate input construction, field/mesh preprocessing, compilation, acceleration structures, tracking, sweeps, total wall time, and peak memory. MC should report 1/(σ2T)1/(\sigma^2T) for a fixed observable; this FOM alone is insufficient when bias is introduced.

For geometry speedup ss and original geometry-time fraction pp, use

Stotal≤1(1−p)+p/sS_{total}\le\frac{1}{(1-p)+p/s}

for basic interpretation. Report expression counts, local program lengths, material/FSR counts, rays, total segments, average/tail evaluation counts, fallback rates, and cache hits.

These are adjustable initial research targets, not literature guarantees or achieved results.

Nearest-intersection error Per-case absolute plus relative tolerance Below minimum feature scale, accounting for grazing conditioning
Geometry-induced assembly eigenvalue shift Initial |Δk|≤10\lvert\Delta k\rvert\le10 pcm Isolate other errors; reference uncertainty substantially smaller

Scan field approximation → root tolerance → FSR scale → track spacing → angular count → iteration threshold independently. Change one factor at a time or use a declared factorial design while converging others. Then examine interactions; biases generally cannot be assumed independent and combined in quadrature.

9. Proposed 24-month schedule and milestones

Months start at project launch; this is neither a funding award nor completed progress.

Stage Months Work and deliverables Progress criterion
A 1–3 Pin versions; mathematical types/interfaces; analytic/adversarial ray library Reproducible references and explicit material/FSR semantics
B 4–7 Bounded surfaces, conservative stepping, root isolation, degenerate fallback, OpenMC prefilter Thin-layer, grazing, hierarchy, and label tests pass
C 8–12 Explicit-3D OpenMOC segmentation; regular/deformed fixed-source tests; local errors Independently validated sequences and volumes
D 13–17 Local pruning/JIT, caching/batching, equal-accuracy cost curves Explainable benefits or explicit failure domain including builds
E 18–21 Assembly/simplified core, response adaptation, MC/MOC comparison Separable errors and converged baselines/new method
F 22–24 Optional Random Ray/few-parameter sensitivities; papers/reproducibility Extensions do not replace forward-reliability acceptance

Suggested paper centers:

  1. Reliable complete traversal and degeneracy handling for multi-material implicit programs: algorithmic conditions, failure semantics, geometry validation.
  2. 3D MOC segmentation errors and source-region adaptation under continuous deformation: geometry/transport error mechanisms and equal-accuracy costs.
  3. Spatial local expression compilation for MC/MOC workloads: material-preserving pruning, cost models, and end-to-end evidence.

These are organizational suggestions. Search interval ray tracing, material-aware implicit representations, direct CAD-MOC, parameterized transport, and shape derivatives before formal novelty claims.

11. Reproducibility checklist

Archive commits, build options, dependencies/compilers, CPU/GPU/thread configuration; nuclear databases and processing; geometry/material/FSR parameters; reference construction; seeds/repetitions; all tolerances; raw intersections and segments; statistical uncertainties; timing boundaries; every failure/fallback record.
