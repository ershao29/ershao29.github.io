1. 核心判断与优先选题

最值得研究的主线是：将具有材料语义和可验证数值界的隐式几何程序，编译为蒙卡事件查询与 MOC 完整分段共同使用的几何服务，并建立几何误差到输运响应误差的联系。

这比“把堆芯写成 SDF”更明确。OpenMC 的 CSG 曲面本来就以隐式方程定义；2017 年也已有 DAGMC-SDF 粒子追踪加速研究。因此，创新空间应落在复杂形变、界面完整性、可验证求交、局部编译、源区划分及输运误差控制上。S24S25

2. 从三组材料中提取什么

2.1 Geometry as Code：应继承“可执行表示”，而非产品宣传结论

来源事实。Courter 将 Geometry as Code 描述为用可组合函数表达几何及工程意图，并将 Omega 定位为语言、模型库和编译体系。文章指出其 WebGPU 前端和 Fidget 网格处理关系，同时明确系统仍处早期、效果证据有限，未来希望开放软件栈。不能据此宣称 Omega 已提供成熟中子输运接口，或已证明优于生产 CAD 内核。S01

研究建议。对输运真正有用的“几何代码”应同时表达：形状参数、材料区、实例层级、边界条件、数值容差和参数有效域。它应生成 CPU/GPU 求值程序，也能输出诊断网格与统一的验证数据。渲染图只是检查入口，完整的材料分区才是物理计算对象。

这里有三层不能混同：

层次输出能否直接支撑输运？
用脚本调用 CAD 内核B-rep/三角面等几何数据仍取决于原几何内核的查询能力
用程序表达隐式场场值、梯度、零面还缺材料语义、界面查询及可靠性条件
面向输运的可执行几何区域标签、距离界、交点事件、完整分段是本研究拟建立的层次

2.2 场的分类：形状正确、距离正确、步进安全是不同要求

来源事实。Courter 区分距离场、单位梯度场 UGF 和零面附近归一化的场；UGF 不必是其零面的精确距离场。偏置和布尔操作对不同场类的作用也不同。相关严谨分析和逻辑保持构造分别可追溯到 Luo 等与 R-functions 文献。S02S03S05S06

本文统一约定与推导。在欧氏空间内取“内负、外正”，研究边界良好的实体区域 Ω\Omega：

dΩ(x)=dist(x,Ω)−dist(x,Ωc). d_\Omega(x)=\operatorname{dist}(x,\Omega)-\operatorname{dist}(x,\Omega^c).

不要用一个 SDF 类型名掩盖下列差异：

对象所需性质可用于什么不能直接推出什么

精确 SDF dd到实体边界的带符号欧氏距离距离查询、物理等距偏置场值就是沿任意射线的命中距离
UGF uu在可微处 ∥∇u∥=1\|\nabla u\|=1特定场运算、局部几何分析全局精确距离；缺少连续性/正则性时也不能自动推出全局 Lipschitz 界
经证明的距离下界 bb0≤b(x)≤dist(x,Γ)0\le b(x)\le\operatorname{dist}(x,\Gamma)不穿过候选界面集 Γ\Gamma 的推进精确偏置、精确法向厚度

例如，区域 x≤0,y≤0x\le0,y\le0 可用 u=max(x,y)u=\max(x,y) 描述。点 (1,1)(1,1) 的场值为 1，到区域边界的真实距离却是 2\sqrt2。其分片单位梯度并不能使它成为精确 SDF。它仍具有全局 1-Lipschitz 性，可提供保守距离界；“不是精确 SDF”不等于“不能安全追踪”。

对精确 SDF，在最近点唯一且可微的位置，x−d∇dx-d\nabla d 给出最近边界点；在中轴、多最近点和尖角处应使用集合值/分支语义。一般场的 x−f∇fx-f\nabla f 没有该保证。

若 f=df=d，d−h=0d-h=0 才具有明确等距偏置意义；对一般扭转场或 UGF，直接减去常数可能改变包壳实际厚度。因而“复杂燃料外层用 f-h 生成”的做法，需要单独验证厚度。

2.4 原文引用中的 Monte Carlo 不等于中子蒙卡

来源事实。Geometry as Code 中“Monte Carlo techniques”链接实际指向 Walk on Stars：其对象是带混合边界条件的线性椭圆 PDE。Intact 链接也是另一类几何分析工具背景。S20S21

本文判断。中子输运的方向、能量、碰撞及裂变源机制不能由布朗运动球跳算法直接替代。可借鉴的是几何查询与无网格计算接口，不能由“同为 Monte Carlo”推断 OpenMC 可用 WoSt 整体替换。若研究扩散近似，应另行说明其物理适用域。

3. 最关键的数学约束与反例

3.1 安全步进依赖范围界，不依赖函数的名字

本文推导。设 ff 在包含当前点与待检查射线段的域 DD 内满足

|f(x)−f(y)|≤LD∥x−y∥, |f(x)-f(y)|\le L_D\|x-y\|,

且候选界面为 f=0f=0。任意域内零点 yy 都有

∥x−y∥≥|f(x)|/LD. \|x-y\|\ge |f(x)|/L_D.

这给出安全推进依据，相关思想已有 sphere tracing 和 segment tracing 前作。S22S23 局部界必须覆盖整个候选步长，并在离开其有效域之前重新评估。

若数值求值满足 |f̃−f|≤ηf|\tilde f-f|\le\eta_f，则可以用

b(x)=max{0,(|f̃(x)|−ηf)/LD} b(x)=\max\{0,(|\tilde f(x)|-\eta_f)/L_D\}

作为上述条件下的下界；计算误差也要计入 ηf\eta_f。接近零面时 bb 可能为零，算法必须切换求根或回退，不能自行加一个大于下界的最小步长而仍宣称有保证。

重要区别：距离下界只说明一段空间内没有界面；它不是 OpenMC distance 所要求的沿方向最近边界距离。最近边界查询必须返回真实候选命中、无命中或明确未决状态，不能把保守小步长冒充表面事件。

3.2 一个能排除错误路线的手算反例

本文推导。考虑一维隐式场 f(x)=x2−1f(x)=x^2-1，区域为 [−1,1][-1,1]。在 x>0x>0 上作 Sampson 式归一化：

g(x)=f(x)|f′(x)|=x2−12x,g′(x)=12+12x2. g(x)=\frac{f(x)}{|f'(x)|}=\frac{x^2-1}{2x},\qquad g'(x)=\frac12+\frac{1}{2x^2}.

取 x=0.5x=0.5：g=−0.75g=-0.75，真实最近边界距离是 0.50.5，且 g′=2.5g'=2.5。沿正方向按 |g|=0.75|g|=0.75 前进会越过边界。虽然在正零点 x=1x=1 有 |g′|=1|g'|=1，全域仍不满足安全步进需要的条件。

因此：

  • f/∥∇f∥f/\|\nabla f\| 可在正则零面附近近似距离，但不是通用精确 SDF，也不是通用保守距离界。
  • 把归一化移到 min/max 之前，可能修复某些分支接缝现象，却不能单独证明任意子场全域 1-Lipschitz。
  • 本例没有布尔运算，已经足以排除“归一化就安全”的一般性断言。

Keeter 的博客给出了布尔接缝归一化产生不连续的实例；本文上述反例进一步界定其经验技巧不能直接承担输运可靠性证明。S13 Courter 的 AUGF 定义强调零面附近，不能扩张为全空间结论。S02

3.3 形变后的几何和物理路径必须分开

本文推导。用可逆映射 x=Tθ(q)x=T_\theta(q) 描述扭转或弯曲，定义

fθ(x)=f0(Tθ−1(x)). f_\theta(x)=f_0(T_\theta^{-1}(x)).

它保持实体对应关系，但一般不保持欧氏距离。若 f0f_0 的 Lipschitz 常数为 L0L_0，且逆映射在适用域具有可验证的 Lipschitz 界，则可构造 LθL_\theta；在适当凸域及可微条件下可用 L0sup∥DT−1∥2L_0\sup\|DT^{-1}\|_2 作上界。

物理空间射线 x(s)=x0+sωx(s)=x_0+s\omega、∥ω∥=1\|\omega\|=1，在参考空间一般变成曲线 q(s)=T−1(x0+sω)q(s)=T^{-1}(x_0+s\omega)。不能把它替换成参考空间直线，也不能直接用参考空间段长计算光学厚度。第一阶段建议始终在物理空间推进，只用逆映射进行场求值。

若形变来自质量守恒的材料运动，还需在相应物理假设下更新密度，例如 ρ(T(q))detDT(q)=ρ0(q)\rho(T(q))\det DT(q)=\rho_0(q)。只变边界、不变密度是一种不同的实验控制条件，应明确标注。

3.4 同号端点不能排除中间薄层

沿射线定义 g(t)=f(x0+tω)g(t)=f(x_0+t\omega)。端点同号可能包围两个根；仅检查符号翻转会漏掉完整薄层。反之，切向重根可能不造成材料切换，不能把每个数值零点都当成跨界。

区间计算若得到 0∉[g](I)0\notin[g](I)，可排除该段零点；若 0∈[g](I)0\in[g](I)，只表示“未能排除”，不证明根存在。一般黑箱场可能有任意密集的根或整段为零；可靠算法必须限定函数族、退化处理和最小可分辨尺度。达到资源上限时报告 unresolved，不能把未解决片段当作真空。

4. 研究方向一：多材料隐式表示与可验证几何接口

研究问题。单个堆芯整体的零面只包含外表面；燃料—包壳—冷却剂等内部材料界面不会自动保留。对材料做整体并集后再追踪，会丢失中子输运需要的内部边界。

研究建议。建立“场程序 + 区域语义 + 共享界面”的中间表示，区分几何实体、材料实例、源区和外部边界：

locate(x,ω)→(cell,instance,material,sourceregion). \mathrm{locate}(x,\omega)\to (\mathrm{cell},\mathrm{instance},\mathrm{material},\mathrm{source\ region}).

每个共享界面只保存一个几何定义及两侧区域信息。默认验证材料域内部互不重叠、并集覆盖问题域；确需覆盖优先级时显式声明，不能靠任意 argmin 或规则顺序暗中决定材料。

拟议接口输出必须验证的契约
classify(point, direction, state)区域/材料/实例标签或边界未决零点、接触面和方向归属一致
enclose(box)场值区间、候选标签、局部有效域包住真值，保留所有可能界面
safe_distance(point, domain)距离下界及有效域不超过到全部相关边界的距离
next_event(ray, state, limit)最近事件、误差区间、界面身份无更早未检查事件；正确处理层级和晶格
segments(ray)有序段长、材料、源区及边界连接无遗漏、无非物理重叠；总长度闭合
normal(event)法线/分支状态光滑点法线正确，非光滑点规则明确

创新空间。不是发明新的 min/max 布尔运算，而是把“场的数学类型、误差界、共享界面和实例身份”纳入输运可验证的编译契约。类型至少区分精确距离、保守下界、仅符号有效和未验证场。

验证。圆柱栅元、相切球、共面邻区、重复燃料实例、薄包壳及重合界面。关键指标是材料序列、界面邻接关系和不同后端标签一致性，而非仅比较表面图像。

5. 研究方向二：最近有效界面与完整特征线分段

5.1 为什么 MC 与 MOC 需要不同查询策略

来源事实。OpenMC 需要沿粒子方向寻找最近边界，并考虑多层 universe/lattice；OpenMOC 则沿预设轨迹在各 FSR 内积分，显式三维分段函数已存在。S25S27S29S31

研究建议。共用几何表达式与查询基础，保留两种执行策略：

工作负载典型需求最有希望的优化
连续能/多群 Monte Carlo在碰撞之前是否跨界？若跨界，最早在哪里？有证据的事件预筛选、最近正根、局部缓存
确定轨迹 MOC轨迹上全部材料和源区段是什么？全交点有序隔离、段批量生成、缓存复用
Random Ray多批随机特征线的源区穿越及积分共享根查询、在线源区发现/细分与缓存

在均匀材料内，若已知全部相关几何边界的距离下界为 bb，且采样碰撞距离 sc<bs_c<b，可跳过精确边界查询；这类思想已有 DAGMC-SDF 前作。S24 但预筛选需要包括父层裁剪和晶格边界，相关计分网格的沿程分箱仍须正确处理。只有“当前位置和终点同属一材料”并不足以排除中途离开后重新进入。

5.2 拟议混合求交算法

  1. 用层级包围盒和区间值排除无关实体，得到按射线距离排序的候选域。
  2. 对有解析解的平面、圆柱等保留解析求交；对有距离界的场作有域限制的保守推进。
  3. 在近界面、薄层或界不足时，将 g(t)g(t) 限定在局部区间内，用区间细分及满足条件的区间 Newton/其他包围求根方法隔离候选事件。
  4. 对每个候选根检查前后区域标签，区分真正跨界、纯切触、重合界面和源区边界；按共享界面身份合并同一事件。
  5. 输出事件位置误差区间。重根、整段共面和无法分离的近重根走显式退化分支；必要时高精度或已有几何后端回退。
  6. MOC 继续遍历到终点，输出所有 FSR 段；MC 根据物理事件上限可提前终止。

“回退”必须针对同一个目标几何。若回退到三角网格，应给出网格逼近误差；不能把不明精度的网格交点作为连续隐式曲面的精确真值。

主要创新候选。把最近根的完备性、材料标签切换与所有源区段的闭合联合验证，并将运行时无法证明的情形显式记录。这比新增一个 sphere tracing 循环更可能形成方法贡献。

应比较的基线。解析 CSG、轴向分层近似、经过误差检查的 DAGMC 网格、全表达式保守步进、无裁剪区间求根；消融局部界、裁剪和回退各自的贡献。

6. 研究方向三：面向输运的表达式裁剪与编译

研究依据。Keeter 和 Lipschitz Pruning 的工作说明，空间局部区域内可以排除不活跃表达式分支；与仅优化每次标量求值相比，降低局部表达式复杂度是另一条有效路径。S12S14

研究建议。保留堆芯实例层级，避免把整个堆芯展开为单个巨型算术表达式。在组件、燃料棒或局部空间块内缓存简化程序。对一个中心 cc、半径 rr 的区域，已证明的界可给出

f(B)⊆[f(c)−LBr,f(c)+LBr]. f(B)\subseteq[f(c)-L_Br,\ f(c)+L_Br].

对一般表达式使用区间运算；对满足条件的场使用上述廉价包络，并由代价模型选择。证据区间严格分离时才裁剪分支。图形渲染中对最终整体形状不活跃的分支，可能仍携带内部材料界面或 FSR 身份，不能仅按总并集场裁剪。

具体子课题：

  • 多输出编译：场值、材料标签、距离界及梯度共享子表达式，但不能共享不兼容的裁剪结论。
  • 可复用缓存：键包含空间域、几何实例、参数版本和数值语义；形变后自动失效受影响项。
  • 轨迹分组：MOC 可按方向、组件或局部程序批处理；MC 的方向和位置更分散，另评估缓存命中和调度开销。
  • 精度分层：远场快速筛选，近界面双精度/更高精度回退；先建立保守参考实现再优化。

实现风险。“采用区间算法”并不自动意味着机器运算具有严格包络。需审计定向舍入、超越函数误差、NaN、溢出、fast-math 和 GPU 浮点语义。Fidget 的求值能力可作为原型基础，但本报告没有证明其现有各后端满足核输运所需的误差证书。S10S11

评价指标。局部程序长度分布、场求值次数、界宽、缓存命中率、编译及重建时间、内存、最终端到端时间。不能只用渲染帧率或单次函数速度证明输运加速。

7. 研究方向四：源区分解与几何—输运误差耦合

7.1 材料区域不等于平源区

研究建议。同一冷却剂材料内部可能存在强通量/源项变化，仍需多个 FSR。采用“两层分区”：物理材料界面由隐式几何定义，源项离散由独立网格或参数分区定义，再求两者交。对于弯曲和扭转结构，源区可以随形状组织，但线段长度仍在物理空间计算。

必须同时研究：源区编号稳定性、几何体积与轨迹估计体积的差异、细小源区的轨迹覆盖、局部泄漏和全局平衡。不能在所有线段长度上施加一个经验修正因子，然后把材料路径误差称为已消除。

OpenMOC 已有 TrackGenerator3D，源码又区分显式三维分段与拉伸区相关路径。因此，连续扭转几何应优先验证通用显式三维分段；不能仅打开 OTF_STACKS 就认定非拉伸几何已被支持。S30S31S32

7.2 从交点误差推到光学厚度误差

本文推导。在常截面、常源项线段内，以实际弧长 ss 写

dψds+Σtψ=Q,ψout=ψine−Σtℓ+QΣt(1−e−Σtℓ). \frac{d\psi}{ds}+\Sigma_t\psi=Q,\qquad \psi_{out}=\psi_{in}e^{-\Sigma_t\ell} +\frac{Q}{\Sigma_t}(1-e^{-\Sigma_t\ell}).

这里 QQ 已含所采用的角度归一化，Σt>0\Sigma_t>0；真空段用极限 ψout=ψin+Qℓ\psi_{out}=\psi_{in}+Q\ell。该积分结构来自 MOC 方程。S29

固定源项、截面和入射通量时：

∂ψout∂ℓ=(Q−Σtψin)e−Σtℓ,δτ=Σtδℓ. \frac{\partial\psi_{out}}{\partial\ell} =(Q-\Sigma_t\psi_{in})e^{-\Sigma_t\ell},\qquad \delta\tau=\Sigma_t\delta\ell.

一条材料段两端的位置误差分别不超过 ϵa,ϵb\epsilon_a,\epsilon_b 时，其长度误差不超过 ϵa+ϵb\epsilon_a+\epsilon_b。若 A/B 界面错移 δs\delta s，保持总路程不变时总光学厚度的一阶误差是

δτ=(Σt,A−Σt,B)δs. \delta\tau=(\Sigma_{t,A}-\Sigma_{t,B})\delta s.

后式还没有包括散射/裂变源、谱及迭代反馈变化；它是选择几何容差的局部指标，不是 keffk_{eff} 的完整误差上界。

对于法向位置误差 δn\delta n，正则横截时近似有

|δs|≈|δn|/|ω⋅n|. |\delta s|\approx |\delta n|/|\omega\cdot n|.

近切向时误差放大，极限处线性近似失效，正是薄层和接触事件需要额外处理的原因。

7.3 建议的科学问题

能否在材料跳跃、方向条件数和响应重要性信息的共同驱动下，为每个界面分配容差，使总计算成本最小而目标响应误差满足要求？

建议先做固定源、单能/少群问题，检查局部关系，再扩展到本征值和组件功率。将总误差按控制实验拆为：几何表示、求交、源区、轨迹/角度、多群截面、迭代及 MC 统计误差；不能仅做一次 OpenMC—OpenMOC 对比就将差值全归因于 SDF。

8. 研究方向五：形变、薄包壳与窄水隙的物理感知自适应

已有背景。弯曲燃料的离散建模比较、ALPHA 的形变处理和螺旋燃料的 MC/MOC 路线已有公开研究，说明应用需求明确，也要求新的隐式方案与已有近似路线公平比较。S35S36S37

研究建议。用连续参数化构造弯曲棒、扭转截面和偏心薄层；分别研究“几何表示更准确”和“相同物理误差下更便宜”这两种收益。先不声称复杂几何一定显著改变整体反应性，应观察局部功率、吸收率和间隙处通量是否更敏感。

Courter 的两体场提供一种间隙坐标启发。在两侧场值均为非负且和不为零的间隙内，可定义

ξ=dA−dBdA+dB. \xi=\frac{d_A-d_B}{d_A+d_B}.

用它安排源区层或重要性采样，是本文建议；曲面间的 dA+dBd_A+d_B 不能无条件解释为处处恒定的真实壁厚/水隙，接触时分母为零，重叠和中轴也需另行处理。S04

建议比较：均匀笛卡尔源区、纯几何曲率细分、按间隙与材料对比细分、再加入初算通量/伴随重要性的细分。评价应为同一源区数或同一内存下的响应误差，避免仅凭更密的局部网格获得表面优势。

若扩展到多物理耦合，进一步研究参数更新后的局部重编译、体积与原子数守恒、源项映射及重定位。形变很小也可能改变接触拓扑，不能仅凭参数变化小就复用所有轨迹。

9. 研究方向六：几何灵敏度与可微输运

研究建议，优先级 P2。在可靠前向几何及分段完成后，研究几何参数对功率、反应率和泄漏的导数，以及制造公差/形变不确定性的传播。先做少参数灵敏度，后考虑逆问题或优化。

本文推导。在唯一、光滑、横截的根 s*(θ)s_*(\theta) 上，若起点与方向固定：

f(x0+s*ω,θ)=0,ds*dθ=−∂θf∇xf⋅ω. f(x_0+s_*\omega,\theta)=0, \qquad \frac{ds_*}{d\theta} =-\frac{\partial_\theta f}{\nabla_x f\cdot\omega}.

若起点或方向也依赖参数，分子还需加入相应链式项。该公式适合分段长度导数；近切触分母趋零，拓扑变化或分支切换处不可直接使用。

来源启发与限制。可微 SDF 渲染研究需要专门处理可见性不连续，说明“场能自动微分”不代表整体路径积分自动可微。S38 中子输运还涉及材料截面跳跃、碰撞路径概率、迭代源和本征值响应；不能直接对 OpenMC 程序做普通 AD 就声称获得无偏几何梯度。

验证路线：解析平板/球壳响应 → 固定轨迹少群 MOC 长度导数 → 有限差分步长收敛 → MC 相关采样或适当的形状导数估计。所有灵敏度实验同时报告导数误差与方差，不以单条随机历史的差分作为结论。

10. OpenMC、OpenMOC 与 Random Ray 如何分工

路线第一阶段工作研究收益不应假定的能力
OpenMC 原生 CSG建立解析参考模型与物理统计基线几何回归、输运参考原生任意隐式程序输入
OpenMC + DAGMC用经验证的 CAD/网格作复杂形状比较独立几何路径、网格收敛参考可视化网格可直接用于可靠输运
OpenMC + 保守预筛选证明下一物理事件前无需界面查询时跳过最小改动的性能研究用下界冒充最近命中
OpenMC + 新隐式曲面/区域接入表达式、方向求交、法线和层级语义复杂几何直接 MC仅增加 Python 包装就完成核心追踪扩展
OpenMOC + 隐式分段先接显式三维 FSR 段生成直接检验全穿越与误差控制原有拉伸区优化适用于任意连续形变
OpenMC Random Ray在选定版本上验证共享几何及源区分解对照固定与随机轨迹的代价与连续能 MC 相同，或现成支持所有新几何后端

OpenMC Surface 的 evaluate、distance、normal 是候选接入接口，但仍需处理输入序列化、边界语义和状态一致性；distance_to_boundary 显式考虑各层几何及晶格。S26S27 OpenMC 的 DAGMC API 可作为现成网格几何基线。S28

Random Ray 已在 OpenMC 官方文档中作为多群随机特征线方法提供，并有源区网格与线性源相关配置；它适合作为扩展对照，但本报告未验证其与拟议隐式后端的兼容性。S33S34

OpenMOC 循环轨迹对反射边界有连接要求。首批算例宜用矩形/平面外边界和复杂内部形状；任意曲面反射会引入离散角度不闭合与轨迹连接问题，应该作为单独课题，而非由一个法线函数顺带解决。S39

11. 可形成的贡献与不宜使用的创新表述

不宜使用的表述更可检验的表述
首次把 SDF 用于核工程面向连续形变多材料几何，提出包含源区语义的可验证全穿越算法，并与 DAGMC-SDF 前作区分
隐式建模代替 CSG在现有隐式 CSG 基础上扩展函数族、证据界和编译后端
SDF 天然无网格、无误差某些连续几何可免于表面网格化；场近似、根求解和输运离散仍有误差
UGF 保证精确距离与包壳厚度按场类别验证距离/偏置性质，必要时构造精确厚度约束或距离重建
GPU 必然大幅加速量化局部裁剪和批处理的收益，并报告端到端时间及精度条件
自动微分即可优化堆芯在横截、固定拓扑条件下验证几何导数，并单独处理路径/界面不连续项

建议组织为三项相互依赖的研究内容：多材料可执行几何及可靠全穿越 → 三维 MOC 分段与误差自适应 → 空间局部编译和跨方法验证。OpenMC 预筛选可作为早期可交付成果，可微输运放在前向模型成熟之后。

12. 结论适用范围

本报告聚焦反应堆中子学计算方法、软件几何接口和验证策略。结论来自所列来源及明确标注的推导，不是全面系统综述或新颖性检索证明。网页、stable 文档及 develop 源码会变化；实施阶段必须冻结版本、核数据、几何参数和运行环境。
