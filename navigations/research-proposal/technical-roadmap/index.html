1. 研究假设与边界

总体假设：在复杂形变、薄材料层及重复实例共存的堆芯中，保留材料语义的局部隐式程序，配合有误差界的界面查询，有机会在相同输运精度下比细密轴向分层或高密度面片更经济。这是假设，不能预先承诺全场景加速。简单平面/圆柱组成的规则模型可能仍以解析 CSG 最快。

建议首先限定：

  • 有限问题域、有限材料集合、可枚举的实体实例，采用内负外正约定和统一长度单位。
  • 分片光滑、连续的场表达式；周期接缝、非光滑布尔和接触事件有显式语义。
  • 可验证的参数范围；禁止几何参数使模型出现未声明的重叠或负厚度。
  • 第一阶段使用静态几何、分区常数截面、平面外边界。连续密度、曲面反射和随时间变化几何后置。
  • 不要求为任意黑箱函数证明有限时间内找全根；算法声明可支持函数族、退化情形及 unresolved 策略。

2.2 原型接口草案

以下是设计草案，不是已实现 API：

GeometryProgram
  classify(point, direction, previous_event) -> RegionState | Ambiguous
  enclosure(spatial_domain, parameter_domain) -> FieldEnclosure
  boundary_lower_bound(point, state, valid_domain) -> CertifiedBound
  next_event(ray, state, t_limit) -> Hit | NoHit | Unresolved
  segmentize(ray, source_partition) -> OrderedSegments | Unresolved

Hit
  t_interval, representative_t
  interface_ids, region_before, region_after
  event_kind: crossing | tangent | coincident | lattice | external
  normal_or_branch_info, numerical_status

OrderedSegments
  [(t_begin, t_end, material_id, source_region_id, instance_id)]
  endpoint_events, unresolved_intervals, provenance

CertifiedBound 表示包络条件已检查；没有证明的距离估计单列为 Estimate。NoHit 表示给定区间内已排除有效事件，而不是达到最大迭代数。Unresolved 进入精度升级或后端回退，生产运行不能静默丢弃。

3. OpenMC 实施路线

3.1 路线 A：几何预筛选，优先证明可用性

DAGMC-SDF 已证明“距离场预筛选 + 原几何查询回退”是一条已有研究路线；新工作应关注更紧的界、形变更新、实例缓存及误差预算，而不是复述这个想法。S24

  1. 在参考几何上提供到当前相关区域边界的保守距离界。
  2. 在已确定下一物理候选事件距离的粒子推进位置，判断是否无需精确边界查询。
  3. 同时取父层裁剪、晶格及其他相关边界的限制；计分网格的路径分箱独立保留。
  4. 界不足时调用原先精确几何路径；记录通过率、误判、回退和额外查询代价。
  5. 固定物理、随机种子和计分设置比较性能，检查是否改变物理统计量。

不能仅修改 Surface::distance()，让其返回一个安全小步长作为“边界距离”；这会把不存在的边界注入事件队列。预筛选应在事件选择语义明确的位置接入。

在均匀宏观总截面 Σt\Sigma_t 下，sc=−lnξ/Σts_c=-\ln\xi/\Sigma_t。若几何界 bb 与当前事件条件固定，则

P(sc<b)=1−e−Σtb. P(s_c<b)=1-e^{-\Sigma_t b}.

本文推导的意义：它提示预筛选收益可能随 Σtb\Sigma_t b 增大而上升；实际收益仍取决于粒子空间/能量分布、界计算开销及层级边界。不能把这一局部概率直接当全局加速比。

3.2 路线 B：原生隐式曲面/区域扩展

OpenMC 公开源码提供曲面 evaluate、沿方向 distance、normal 等接口，几何追踪还有多层坐标与晶格处理。S26S27 候选工作包：

  • 增加有界复杂曲面类型和表达式序列化，不将用户 Python 回调放进粒子热点循环。
  • 明确布尔复合实体与单个曲面的职责；对于复合区域的零面事件，要检查其是否在当前 cell 上有效。
  • distance 返回最近有效正向命中；正确使用表面重合提示，避免重复命中起点。
  • 保留稳定的表面、cell、实例 ID，用于跨界、计分、分布式材料及诊断。
  • 逐项验证平移/旋转、父层裁剪、lattice 退出、真空/透射，随后测试反射和周期。
  • 对输入/重启/几何可视化和随机体积计算等关联功能做兼容检查。

第一阶段不修改碰撞核和核数据处理。若保持几何不变且仅改查询器，应能在同一统计设计下检验无可分辨的响应偏差。

4. OpenMOC 实施路线

OpenMOC 官方用户文档包含三维轨迹接口；公开源码中的 Geometry::segmentize3D 是直接分段的候选入口，而 segmentizeExtruded 等路径与拉伸结构有关。S30S31S32

4.1 先替换几何分段，再动输运扫掠

  1. 固定已有轨迹起点、方向、权重和外边界连接。
  2. 由新内核生成同一条轨迹的全部材料/FSR 段，转换为求解器所需的数据结构。
  3. 初期用显式存储确认段序列与扫掠结果，再研究按需生成和缓存。
  4. 比较 FSR 体积的独立几何积分与轨迹积分，检查细源区是否被漏采。
  5. 在体积、FSR 编号和连接一致后再启用 CMFD 等加速，避免把耦合错误混入几何验证。
  6. 在固定平面边界的条件下完成三维扭转/弯曲验证，再考虑复杂反射边界。

源区边界是积分离散边界，即使两侧材料相同也不能随意合并。相邻段是否可合并取决于材料、源区、计分以及加速方程所需的状态是否全部一致。

4.2 批处理与按需分段

比较三种方案：一次性显式段存储；每次扫掠重建；以局部几何版本为键的分段/程序混合缓存。总成本写为

T=Tbuild+Tcompile+Ttrack+NsweepTsweep+NupdateTupdate. T=T_{build}+T_{compile}+T_{track} +N_{sweep}T_{sweep}+N_{update}T_{update}.

几何静态、扫掠次数多时，昂贵的首次分段可能被摊销；每轮都改形状时则不同。不能把单次 track generation 加速与整个求解器加速混为一谈。

每类同时做随机射线与结构化对抗射线。近边界起点、平行/近切向、超薄层与跨尺度坐标必须主动采样，不能靠均匀随机射线偶然命中。

建议把几何总尺度归一化为 1 后测试多级薄层比值，例如 10−2,10−4,10−610^{-2},10^{-4},10^{-6}；这只是数值压力测试，不代表真实堆芯尺寸。再以真实单位检查容差缩放一致性。

5.2 第一层：固定源、同物理问题

使用无裂变或固定裂变源的单能/少群算例，核对泄漏、吸收和分区反应率。参考与新后端采用相同材料、相同截面与边界。这样可以先排除源迭代、连续能到多群压缩等混杂因素。

解析纯吸收平板特别适合检查 e−Σtℓe^{-\Sigma_t\ell} 及错移界面的光学厚度误差。随后增加散射，检验路径误差是否被迭代放大。

5.3 第二层：规则几何回归

选择公开规则栅元/组件基准，例如经明确版本和输入核实的 C5G7 系列算例。先要求隐式后端与原解析几何在同一离散下收敛到一致结果，再引入弯曲/扭转。

注意：对公开基准做形变后得到的是自定义派生问题，不能继续把原发布参考值当作其正确解。原始输入、变形规则及新参考求解过程必须一起归档。

5.4 第三层：连续形变与多材料结构

几何家族参考比较重点响应
连续扭转非圆截面燃料轴向分层序列、独立 CAD/网格序列轴向/径向功率、局部反应率、计算代价
C/S 形弯曲棒与组件可解析特例、旋转段与堆叠模型水隙通量、功率倾斜、泄漏
偏心薄包壳和窄水隙精确层厚模型、网格收敛壳层吸收、材料弦长分布
多实例组件或简化堆芯规则无形变退化极限层级缓存、规模扩展、端到端时间

仅有 OpenMC 与 OpenMOC 相互一致不足以证明几何正确，因为它们可能共享同一错误内核。至少保留一条独立几何参考路径；参考网格必须做水密、体积、共享面和薄层收敛检查。S18S19

5.5 第四层：多物理与导数扩展

先固定温度/密度研究纯几何效应，再在明确守恒条件下引入密度、温度和材料映射。导数研究先验证简单参数，再研究接触前后的非光滑性。此阶段不应成为前向几何论文的必要门槛。

6. 需要报告的指标

6.1 几何正确性

  • 最近有效事件误差、材料序列一致率、遗漏界面数、重复界面数。
  • 最大段长误差、材料累计路径长度误差、全轨迹长度闭合误差。
  • 切触分类、共面/重根处 unresolved 比例和回退后的结果。
  • 不同后端、线程数、坐标缩放及表达式重排下的一致性。
  • FSR 独立体积误差、漏采源区数、轨迹重建体积与覆盖分布。

若目标段长为 LL，建议记录

eclose=|∑jℓj−L|max(L,Lscale), e_{close}=\frac{|\sum_j\ell_j-L|}{\max(L,L_{scale})},

其中 Lscale>0L_{scale}>0 为预先规定的小长度尺度；同时报告绝对误差，避免小量归一化掩盖问题。

6.2 输运正确性

记录 keffk_{eff}、分区通量、功率归一化后的 RMS/最大偏差、吸收/裂变反应率、泄漏和离散方程平衡残差。低响应区的相对误差可能失真，应同时给绝对或体积加权误差。

本文建议使用明确的本征值差定义

Δk[pcm]=105(ktest−kref), \Delta k\,[\mathrm{pcm}]=10^5(k_{test}-k_{ref}),

并与反应性差 105(1/kref−1/ktest)10^5(1/k_{ref}-1/k_{test}) 区别，不混用单位相同但量不同的指标。

两个独立 MC 估计量比较时，差值标准差可取 σ12+σ22\sqrt{\sigma_1^2+\sigma_2^2}；相关采样则应包括协方差。不要只因为结果落在很宽的置信区间内就宣布误差满足工程目标。

6.3 性能与规模

分别报告输入构造、场/网格预处理、编译、加速结构、追踪、扫掠、总壁钟时间及峰值内存。MC 还报告固定物理量的 1/(σ2T)1/(\sigma^2T)；若引入偏差，该 FOM 本身不足以衡量质量。

对几何查询加速比 ss、原几何耗时比例 pp，总加速上限可用

Stotal≤1(1−p)+p/s S_{total}\le\frac{1}{(1-p)+p/s}

作基本解释。报告字段包括模型表达式数、局部表达式长度、材料/FSR 数、射线数、全部段数、平均和长尾求值次数、回退率及缓存命中率。

7. 建议验收门槛与误差预算

下列数值是启动实验时可调整的研究目标，不是文献保证，也不是已达到的结果。

项目建议门槛解释
结构化几何反例库无已知漏层、错标签或静默未决有限测试通过不等于数学全局证明
大规模随机射线回归预先固定至少 10610^6 条，报告零失败或完整失败清单不用随机测试替代切线/薄层测试
最近交点误差满足每例预先给出的绝对＋相对容差容差应小于最小特征尺度，并考虑近切向条件数
几何造成的组件本征值变化初始目标 |Δk|≤10\lvert\Delta k\rvert\le10 pcm应隔离其他离散误差；参考统计误差须显著小于目标
几何造成的局部功率误差初始目标 RMS ≤0.1%\le0.1\%、最大 ≤0.5%\le0.5\%需明确空间归一化、低功率屏蔽规则及统计不确定性
性能在相同精度下报告成本曲线，允许某些场景无加速不设置脱离基线的统一倍数承诺

建议采用独立容差扫描：场逼近误差 → 根容差 → FSR 尺度 → 轨迹间距 → 角度数 → 迭代阈值。每次只改一项或使用明确的因子设计，其他项收敛到足够小。最终再检查误差交互；通常不能假定这些偏差相互独立并直接平方求和。

8. 消融实验与可证伪结论

假设必须比较若不成立，仍可形成什么结论
局部编译优于全表达式求值无裁剪/区间裁剪/Lipschitz 裁剪；含构建时间给出有益的复杂度和复用率区间
保守界可减少 OpenMC 查询关闭/开启预筛选，改变 Σtb\Sigma_t b 分布明确低碰撞频率/高界开销时不适用
直接隐式几何比分层近似更有效相同响应误差下的分层数和总成本给出何时等效几何已足够，避免过度建模
间隙/响应驱动 FSR 优于均匀细分同 FSR 数、同内存、同角度配置分辨几何细节与源项分辨率的真正主导因素
新分段可直接支持非拉伸三维 MOC规则退化极限、连续扭转和弯曲模型确认哪些 OTF 假设必须重新设计
几何导数有用解析导数、AD/伴随、有限差分及统计误差划定横截与拓扑变化的可微适用域

  1. 多材料程序隐式几何的可靠全穿越与退化处理：贡献是算法条件、失效语义和几何验证。
  2. 连续形变几何下三维 MOC 的分段误差与源区自适应：贡献是几何—输运误差机制和同精度成本比较。
  3. 面向 MC/MOC 工作负载的空间局部表达式编译：贡献是保留材料语义的裁剪、代价模型和端到端证据。

上述题目只是组织方式；正式声称新颖性之前，应继续检索区间射线追踪、材料隐式表示、直接 CAD-MOC、参数化输运与形状导数文献。

10. 风险与可保持价值的替代路线

风险应对
Omega 栈不可直接获取或接口变化使用独立的最小表达式图；Omega 作为理念来源，不设为必需依赖
任意场的 Lipschitz 界过松局部域细分、方向界、区间求根及解析基元混合；不要放松安全性换速度
根隔离在退化点成本过高显式识别相切/共面；限制函数族；记录回退开销与未决案例
Fidget 数值语义不能满足严格包络复用结构思想，保留独立双精度/区间参考实现；优化实现接受差分审查
OpenMOC 的 OTF 路径不适用非拉伸形状先显式三维分段；研究新的局部按需方案，而非强行套用拉伸区结构
与 OpenMC 对比混入多群截面误差先同多群固定源，再做连续能到多群的独立收敛与误差分析
网格参考自身失真解析特例、高精度根与独立网格三方比较；对网格做几何及物理收敛
大模型没有端到端性能优势给出适用域和负面结果；仍可保留可靠性及误差分析贡献
